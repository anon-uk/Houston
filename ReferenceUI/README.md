# Mission Center UI reference snapshot

The full resources directory (including every UI Blueprint and the icon
resources) and all repository reference screenshots were copied from Mission
Center at f4109d6ac4d467b3416969d3d17dcdd8c32989c9.
The graph-widget renderer sources are also included for reference.

These reference files retain their original GPL-3.0-or-later license and
copyright notices. They are not linked into the app. The app adapts their
layout and rendering behavior into native SwiftUI/AppKit code.

Source: https://gitlab.com/mission-center-devs/mission-center
Graph widget: https://gitlab.com/mission-center-devs/graph-widget
